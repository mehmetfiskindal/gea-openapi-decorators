## ⚡ The Challenge with GeaStack & Decorators

[GeaStack](https://github.com/geastack/compiler) (`geatsc`) compiles TypeScript **directly into native C++ binaries Ahead-Of-Time (AOT)** without a JavaScript engine (V8, JavaScriptCore). 

Traditional decorator frameworks (NestJS, Ts.ED, express-openapi-decorators) rely on:
- Runtime reflection (`reflect-metadata`)
- Dynamic property indexing (`instance[methodName].bind(instance)`)
- Dynamic class instantiation (`new (controllerClass)()`)
- Dynamic parameter spread (`handler(...args)`)

In GeaStack's AOT C++ model, these dynamic patterns produce compiler **refusals** because C++ requires static vtables, fixed function calling conventions, and compile-time known layout types.

---

## 💡 The Solution: Ahead-of-Time (AOT) Route Generation

`@developersailor/gea-openapi-decorators` solves this with a **build-time AST code generator**:

1. You write clean, expressive NestJS/Hono-style controllers with TypeScript decorators.
2. The CLI (`gea-openapi codegen`) analyzes your controller AST at build time.
3. It emits:
   - **`routes.generated.ts`**: Pure, static, zero-reflection Hono route registrations.
   - **`openapi.json`**: Complete, validated OpenAPI 3.1 specification.
4. GeaStack compiles the generated routes directly into blazing-fast native C++ with **0 refusals** and **260,000+ req/s** throughput!

## 🚀 Quick Start

### 1. Write your DTOs and Controllers

```ts
// src/controllers/user.controller.ts
import {
  Controller,
  Get,
  Post,
  Param,
  Body,
  Query,
  ApiTags,
  ApiOperation,
  ApiResponse,
  ApiProperty,
} from '@developersailor/gea-openapi-decorators';

export class CreateUserDto {
  @ApiProperty({ description: 'User full name', example: 'Alice Smith' })
  name: string;

  @ApiProperty({ description: 'User email', example: 'alice@example.com' })
  email: string;
}

@ApiTags('Users')
@Controller('/users')
export class UserController {
  @ApiOperation({ summary: 'Get user by ID' })
  @ApiResponse({ status: 200, description: 'User found' })
  @Get('/:id')
  async getUser(@Param('id') id: string) {
    return { id, name: 'Alice Smith' };
  }

  @ApiOperation({ summary: 'Create a new user' })
  @ApiResponse({ status: 201, description: 'User created' })
  @Post('/')
  async createUser(@Body() body: CreateUserDto) {
    return { id: 'new-id', ...body };
  }
}
```

---

### 2. Run the Code Generator

Run the CLI before compiling:

```sh
npx gea-openapi codegen \
  --controllers src/controllers/*.controller.ts \
  --models src/models/*.dto.ts \
  --out-routes src/routes.generated.ts \
  --out-openapi public/openapi.json
```

---

### 3. Generated Static Routes (Zero-Reflection)

The generator creates `src/routes.generated.ts`:

```ts
// Auto-generated by @developersailor/gea-openapi-decorators. DO NOT EDIT.
import type { Hono } from 'hono';
import { UserController } from './controllers/user.controller.js';

export function registerRoutes(app: Hono): void {
  const userController = new UserController();

  app.get('/users/:id', async (c) => {
    const param_id = c.req.param('id');
    const result = await userController.getUser(param_id);
    if (result instanceof Response) return result;
    if (result === undefined || result === null) return c.body(null, 204);
    return c.json(result, 200);
  });

  app.post('/users', async (c) => {
    const body_body = await c.req.json();
    const result = await userController.createUser(body_body);
    if (result instanceof Response) return result;
    if (result === undefined || result === null) return c.body(null, 201);
    return c.json(result, 201);
  });
}
```

---

### 4. Plug into Hono & Compile with GeaStack

```ts
// src/server.ts
import { Hono } from 'hono';
import { registerRoutes } from './routes.generated.js';

const app = new Hono();

// Register the AOT routes
registerRoutes(app);

// Serve static OpenAPI document
app.get('/openapi.json', (c) => {
  return c.json(require('./openapi.json'));
});

export default app;
```

```sh

Options:
  -c, --controllers <files...>  Controller file paths or globs
  -m, --models <files...>       Model/DTO file paths or globs
```

## 📋 Supported Decorators

| Decorator | Target | Description |
|-----------|--------|-------------|
| `@Controller(basePath)` | Class | Defines base path for all routes in class |
| `@Get(path)` | Method | Registers HTTP GET route |
| `@Post(path)` | Method | Registers HTTP POST route |
| `@Put(path)` | Method | Registers HTTP PUT route |
| `@Delete(path)` | Method | Registers HTTP DELETE route |
| `@Patch(path)` | Method | Registers HTTP PATCH route |
| `@Param(name)` | Parameter | Injects route parameter (`c.req.param(name)`) |
| `@Query(name)` | Parameter | Injects query parameter (`c.req.query(name)`) |
| `@Body()` | Parameter | Injects parsed JSON request body (`await c.req.json()`) |
| `@Header(name)` | Parameter | Injects request header (`c.req.header(name)`) |
| `@Ctx()` | Parameter | Injects raw Hono context `c` |
| `@ApiTags(...tags)` | Class/Method | Groups endpoints in OpenAPI |
| `@ApiOperation(options)` | Method | Summary & description metadata |
| `@ApiResponse(options)` | Method | Response schema and HTTP status codes |
| `@ApiProperty(options)` | DTO Property | Model property description, example, types |
